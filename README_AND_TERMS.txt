PRODUCT OVERVIEW:
HM DeepScan is an advanced forensic-grade data acquisition and analysis platform 
built by HMSTUDIOS.TECH. Operating over low-level Android Debug Bridge (ADB) 
protocols, it performs non-destructive logical filesystem extraction targeting 
media, gallery artifacts, structural database headers, EXIF location metadata, 
and cached assets.

Unlike basic surface-level mobile recovery applications, HM DeepScan works
directly with raw data streams, binary EXIF tags, and AES-256 encrypted
database structures to isolate and organize mobile artifacts into structured
HTML dossier reports.

------------------------------------------------------------------------
WHAT HM DeepScan DELIVERS:
------------------------------------------------------------------------
1. WhatsApp & Gallery Media Recovery:
   Executes deep logical extraction over USB (ADB) to pull WhatsApp photos, 
   videos, voice notes, documents, stickers, and cached gallery media 
   associated with WhatsApp storage.

2. Deep-Level Artifact Scanning:
   If physical remnants, orphaned cache blobs, or un-overwritten data exist 
   on your device's filesystem, HM DeepScan will locate and extract them 
   into an organized folder alongside an interactive HTML forensic report.

3. AES-256 Database Decryption Engine:
   Includes a native decryption module for encrypted WhatsApp database 
   archives (.crypt14). If you possess the matching 158-byte cryptographic 
   key file from your device, HM DeepScan will decrypt the archive into a 
   readable SQLite database.
   (Note: For legal and security compliance, HM DeepScan does NOT extract 
   or bypass key files without device authorization. The user must provide 
   the key file).

4. EXIF Geolocation & Camera Metadata Extractor:
   Extracts hidden camera hardware specs, lens metrics, timestamps, and 
   GPS coordinates from photos, generating a direct Google Maps link.

------------------------------------------------------------------------
REALISTIC TECHNICAL EXPECTATIONS & BOUNDARIES:
------------------------------------------------------------------------
- THE OVERWRITE REALITY:
  If data has been physically overwritten by operating system activity or 
  wiped via factory reset on modern encrypted storage (Android 10+ File-Based 
  Encryption), NO SOFTWARE TOOL IN THE WORLD can recover it electrically.

- THE SOFTWARE LIMIT:
  HM DeepScan reaches the absolute maximum technical capability of software-level 
  logical extraction over USB. If HM DeepScan cannot locate data remnants on 
  the storage sectors, the ONLY remaining alternative on Earth is a hardware-level 
  laboratory forensic chip-off service, which costs thousands of dollars in 
  specialized security labs.

STEP-BY-STEP GUIDANCE & LAUNCH FLOW:
------------------------------------------------------------------------
Step 1: Download & Initial Workstation Setup
  - Extract the downloaded package to a folder on your Windows 10/11 PC.
  - Make sure your Android device has a data-capable USB cable plugged into 
    your PC.

Step 2: Enable USB Debugging on your Android Device
  - Open Settings > About Phone on your Android phone.
  - Tap "Build Number" 7 times until it displays "Developer mode enabled".
  - Go to Settings > System / Developer Options > Enable "USB Debugging".

Step 3: Launching HM_DeepScan.exe (Windows Security Note)
  - Double-click `HM_DeepScan.exe`.
  - Windows SmartScreen may show a prompt ("Windows protected your PC"). 
    Click "More info" and select "Run anyway". (This occurs because HM DeepScan 
    is a new, specialized security tool).

Step 4: Product Activation
  - On first launch, the tool will request your 16-character Beta License Key.
  - Enter your assigned key (e.g., HM-BETA-XXXX-XXXX) provided in your receipt.
  - Upon valid entry, your workstation will be licensed, saving a local 
    `hm_license.lic` file.

Step 5: Connecting Device & Executing Scans
  - Unlock your phone screen. When a prompt appears on your phone screen 
    asking "Allow USB Debugging?", check "Always allow from this computer" 
    and tap "ALLOW".
  - From the HM DeepScan main menu:
      Select Option [2] to perform Android Device Recovery.
      Select Option [3] to Decrypt .crypt14 Databases (if key file is present).
      Select Option [4] for Photo EXIF Location Extraction.
